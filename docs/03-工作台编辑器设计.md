# 教师视频编辑器 v0.2

用户已确认：集中开发工作台，支持教师修改生成视频并导出；集成字幕时间轴、简单剪辑、背景音乐与配音。沿用前一轮确认的标准工程、共享渲染和全文单一来源方向。

## 交付范围

- 逐幕动态播放；所有画面文字可列出、定位、修改、调整字号与位置。
- 可视化组件选择、拖动、缩放、旋转、隐藏；布局变换与原动画分层。
- 字幕增删、起止时间、拖动时间条、SRT 导入导出；源文本为唯一内容来源。
- 镜头拆分、复制、排序、删除、入出点裁剪和末尾停留；保留来源动画的时间段。
- 背景音乐／配音上传，录音，位置、音量、源起点、淡入淡出与静音；工程携带音频。
- 自包含 SVGFilm JSON 保存与回读；静态 SVG 导入；携带 SVGFilm 数据的 HTML 导入与独立播放 HTML 导出。
- 本机服务提供 MP4 渲染、进度、取消与下载；使用与编辑区相同的 renderer。

## 实现

现有工作台目录继续作为产品目录。原生 SVG 源码保留为受支持的细胞适配器，新增通用 SVG 场景。浏览器模块负责数据、渲染、编辑、音频；Python 本机服务负责本地文件与 FFmpeg 导出。应用不依赖前端框架或 CDN。

工程 v0.2 的 `sources` 声明来源：`cell-native-v1` 使用随工作台分发且版本固定的原生绘制组件；`svg` 携带经清理的完整矢量素材。`scenes` 是独立编辑的时间片，每片有稳定 ID、sourceId、in/out/hold、texts、subtitles、objectOverrides。源时间为 `in + min(local, out-in)`；片长为 `out-in+hold`。文本与对象 ID 由对应来源版本确定，写入工程后保持稳定。

拆分剪辑使右片 source in 前移；字幕按切点裁剪并变为各片局部时间。场景文字的出现时间维持来源时间，组件布局覆盖在动画外层。音轨采用全片时间，剪辑不隐式改变其位置，界面明确显示全片音轨。

编辑和导出共享 SVG renderer、文本布局与时间求值；字幕不保留第二份内容 rows。原生文字使用可编辑 SVG text，默认本机楷体，预览与本机导出使用同一字体环境。远端机器须具有所选字体，字体不自动分发。

音频预览按全片时间同步，导出由 FFmpeg 按相同开始时间、源偏移、长度、增益和淡入淡出混音。录音只在用户主动点击后请求麦克风。

普通 SVG 导入为静态镜头；带规范数据的 HTML 恢复工程。任意脚本 HTML 不执行。首版不承诺任意 MP4 的对象编辑，也不接入在线 TTS 或云发布。

## 按需工作区与批量组件编辑（已验收）

用户明确要求新增两项：按需展开工作区并拉高时间轴；框选组件后批量移动，并可选择分别缩放或整体缩放。

实现范围：镜头列表、属性区、时间轴独立开关；默认收起属性区和时间轴轨道，播放栏保留；时间轴上缘拖动与键盘调高，窗口改变后限制在可用高度内，布局偏好本机保存。选择工具支持空白拖框、显式框选模式、Shift追加／取消和Esc清除；双击或“编辑所选”打开属性区。默认选完整组件，可切换深入部件。框选采用完整包围，父子去重，避免重复变换。

变换语义：分别缩放以各组件当前可见中心为锚点；整体缩放以选择框中心为锚点，尺寸与间距同倍率改变。统一舞台坐标下计算操作，再换算到各对象父坐标，不破坏内层动画。结果继续存入既有objectOverrides，单次拖动／批量操作对应一次撤销；不创建新的永久分组或变更工程协议。

实施顺序：先验证父子去重和坐标变换数学，再加入工作区控件与画布多选，最后通过真实浏览器验证嵌套变换、缩放差异、布局恢复、保存回读和共享渲染。核心改动分别放在selection.mjs、canvas-selection.mjs、workspace.mjs，编辑器负责把这些操作连接到现有事务与撤销。

实现及验收已完成。选择、框选与缩放统一采用可见图元边界，隐藏子节点不改变缩放锚点；时间轴高度按实际工具栏、选中工具条及内边距动态限制。取消活跃手势优先于输入框快捷键，避免临时拖动进入历史。全部新功能继续使用原有工程字段，无协议迁移。

## 精细时间轴（已验收）

用户要求加入磁吸、自动对齐等常用剪辑辅助。实施范围：可开关磁吸与可选吸附距离，吸附播放头／工程边界／镜头与字幕、音轨边缘，显示参考线；Alt临时绕过磁吸；按项目帧率或毫秒编辑；首尾对齐播放头、裁剪至播放头、贴齐同类前段；帧级微调与精确时刻输入；字幕／音频／镜头边缘拖动、音频源偏移联动、镜头拖动排序；边缘自动滚动、播放头连续拖动、锚定缩放与适应全片。

延续现有数据语义：字幕仍属于各自镜头；镜头序列无空隙并自动接续，裁剪镜头不暗中挪动全片音轨。片段移动保持时长；音频头部裁剪保持源声音的对应关系；音频裁短时淡入淡出不超过新长度。原工程的亚帧时间不批量迁移，吸附已有参考点时优先精确贴合，普通拖动使用当前精度。

时间规则集中到timeline.mjs，交互由timeline-controller.mjs负责；拖动只预览候选，松手验证并一次性提交，Esc／Ctrl+Z取消，不产生半次编辑。选中片段才显示精细操作条，保持默认轻量工作区。验收覆盖吸附与绕过、不同缩放、帧率、源边界、撤销与保存、窗口变化及实际导出。

实现与验收已完成。共享project.mjs统一场景边界容差和导出帧数；字幕裁切统一处理过短残片；合法亚帧镜头保持可选。镜头头部参考线明确标为“裁剪参考”，后续会移动的镜头边界不参与该裁剪的磁吸。旧音轨缺少时长元数据时保留原来已知源范围，避免越裁越短。具体操作见产品说明，测试与实测证据见当前进度。
