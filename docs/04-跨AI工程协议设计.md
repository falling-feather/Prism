# 跨 AI 工程协议与工作区 Skill

## 已确认目标

其他 AI 在不依赖本次对话的情况下，可以创建工作台能导入、编辑、保存和导出的 SVG 动画工程。只规定开发接口和数据契约；风格、脚本审批与创作流程不在本轮范围。用户已确认同时实现通用动画接口，并要求 Skill 仅安装在当前工作区，另交付完整单文件 Markdown 提示协议。

## 接口决定

- SVGFilm 0.3 新增 `svg-keyframes-v1` 来源；旧 0.2 工程继续可读并在编辑器载入时升级版本，保留既有 ID 和修改。旧版工作台拒绝新版工程，避免动画被当成静态图。
- 素材仍自包含，JSON 是工程真相；ZIP／标准 HTML 只是封装。通用动画由 SVG 和声明式关键帧组成，不执行第三方脚本。
- 新来源的可编辑图形和文字具有稳定 SVG `id`；工作台用 `sourceId:o:svgId`／`sourceId:t:svgId` 登记对象和文字。首次作者交付可让 `objects`、`texts` 为空，由工作台登记；已编辑工程必须保留清单与 ID。
- 动画按来源时间确定性求值，支持 x/y、统一 scale、rotation、opacity；关键帧从0开始、严格递增，超出末个关键帧保持。每段缓动写在起始关键帧上，支持 linear／ease-in／ease-out／ease-in-out／step。
- 单个动画目标使用父坐标中的 origin；布局覆盖在动画外层，原 SVG 基础变换位于内层，教师修改不覆盖运动。裁剪、拆分、停留沿用现有来源时钟，字幕仍为剪辑局部时间，声音仍为全片时间。
- 协议 Skill 位于 `.agents/skills/svgfilm-authoring/`；完整字段规范集中在其 references，最小动画示例在 assets。校验脚本复用工作台的实际校验与渲染代码，不另写一套判断实现。纯文档从同一内容生成到 docs，不手工维护第二份协议。

## 实施与验收计划

由当前会话直接实现，使用 writing-plans 与 TDD 的分步验证方式。保持现有目录职责；测试产物放在工作台 `.work`，不安装全局 Skill。

1. **数据与动画规则**：新增 `src/animation.mjs`，提供 `validateAnimations(source)`、`sampleTrack(keys,time)`、`sampleAnimation(animation,time)`；扩展 `project.mjs` 的版本／来源验证。先验证任意顺序求值、关键帧边界、缓动、非法通道／值／版本，再实现。
2. **稳定绑定与共享渲染**：新增 `src/svg-contract.mjs` 检查新版 SVG 的 ID、文字与资源限制；扩展 `renderer.mjs` 绑定目录与独立动画层。真实浏览器验证重排 SVG 后 ID 稳定、缺失目标明确报错、文字编辑、批量变换、拆分裁剪、保存回读。
3. **导出和旧工程**：`server.py` 的独立 HTML 捆绑包含新模块，导出使用相同 renderer；服务与启动器报告新版能力。验证 0.2 迁移、旧细胞动画、离线 HTML 及实际 MP4 动画抽帧。
4. **协议 Skill 与纯文档**：编写 `SKILL.md`、字段／SVG／动画／验收参考、完整独立示例；新增项目校验与单文件协议生成脚本。以未接触实现的新代理依文档制作另一题材工程，再实际导入验证，不能以字段文本检查代替运行。
5. **交付检查**：运行现有核心测试和受影响的浏览器流程，完成独立审查，更新产品说明／进度；仅提交本轮变更。

## 重点检查

- 跳着拖动、倒放寻帧和重复寻帧不能累计变换或依赖墙上时钟。
- 动画层不得吞掉教师布局覆盖，嵌套动画仍可框选、移动和缩放。
- 未知通道、失效引用、重复 ID、动画节点或外部脚本不能静默丢弃后声称兼容。
- 旧工程迁移不重新编号；复制剪辑的文字和布局覆盖保持独立。
- 纯文档必须独立可用；Skill 目录可移交其他工具，但真实导入校验需要匹配版本工作台，不能假报已验证。

协议的具体字段、限制与命令以 Skill 参考和源码为准，本文件记录设计和验收范围。
