# Prism v0.3.0 验证记录

验证平台：Windows、Microsoft Edge、Python 3.14、Node 24、FFmpeg。浏览器检查使用独立的 Playwright 会话，不复用用户正在编辑的页面。

## 已覆盖

- 44项核心测试：工程验证、剪辑时钟、字幕裁切、音频包络、组件变换、磁吸、帧级微调及声明式动画求值。
- Edge编辑闭环：图文修改、拖动、删除与批量编辑、撤销重做、时间轴、音频导入、保存回读。
- 动画协议：稳定ID、逆序寻帧、裁剪与停留、布局覆盖、资源引用、离线HTML、旧工程迁移。
- 图文删除：当前镜头隔离、输入焦点保护、保存回读和独立HTML输出。
- 布局：桌面与窄屏窗口、时间轴高度和面板折叠；媒体检查会拒绝损坏图片／音频。
- 实际MP4：静态与动态SVG、音频混合、剪辑边界及帧数；关键帧叠加教师位移后抽帧位置符合预期。
- 协议可用性：独立AI上下文仅读纯文档生成的新题材工程，通过实际导入检查；未声称已调用Claude或DeepSeek服务进行验证。

## 首次公开发布检查

目录调整后重新运行核心测试、实际浏览器编辑和MP4导出；公开文件快照独立启动，确认运行不依赖本地研究资料、虚拟环境目录、旧字体轮廓缓存和历史输出文件。

macOS／Linux、真实麦克风权限与录音、完整334秒样片的重新渲染及人工试听。长片、复杂外部SVG、特殊字体和第三方生成工程仍建议先用短片试用。
