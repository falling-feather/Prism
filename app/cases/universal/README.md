# 通用编辑示例

- `clockwork.svgfilm.json`：函数组合绘制的时钟。可修改钟面颜色、指针长度和转速；指针属于钟面子对象。
- `cards.svgfilm.json`：类实现的图片与文字场景。包含真实PNG资源、可编辑多行文字和运动方式参数。
- `mixed.svgfilm.json`：上述两种Canvas场景与SVG关键帧共用时间轴。用于检查跨来源寻帧、保存与导出。

在映物点击“导入”，选择对应JSON；点击“属性”展开编辑面板。“追加工程”可将示例加到已打开的工程后面，保留原有修改。

这些示例独立于《一秒钟》或细胞作品，使用同一公开接口。字段说明的唯一来源是 [SVGFilm 0.4](../../docs/SVGFilm_工程格式_v0.4.md)。
